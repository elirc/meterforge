# Sprint 13: Reconciliation, refunds, and disputes

Reconciliation compares internal and provider facts and returns an exact signed difference; it does not overwrite either source. Refunds are new records linked to payments, constrained by currency and original amount. Disputes retain provider case identity and disputed money.

These are compensating and evidentiary records. Treating them as edits to a payment would erase the history operators need to explain financial state.
