# Release checklist

## `v1.0.0` curriculum release

- [x] Fifteen sprint milestones and sixty issues have implementation evidence.
- [x] Five deliberate flaws have failing counterexamples and repairs.
- [x] Locked restore, formatting, Release build, tests, and vulnerability audit run in CI.
- [x] Health, operations, integration, testing, and over-engineering guidance is published.
- [x] No real credentials, card/bank data, proprietary code, or production claims are included.

## Before any real deployment

- [ ] Authenticated tenant claims and role/scope enforcement.
- [ ] Fully wired durable transactions, migrations, atomic outbox, and tested restore.
- [ ] Compliant payment/tax providers, managed secrets, signed webhooks, and reconciliation ownership.
- [ ] Financial/privacy policy owners, encryption, retention/deletion, and audit access controls.
- [ ] Load evidence, telemetry, dashboards, alerts, SLOs, on-call, and disaster-recovery rehearsal.
