# M1 — reference port review

Proof outputs marked **[measured]** were run against the lab container (SQL Server 2022, server collation `SQL_Latin1_General_CP1_CI_AS`); see `training/lab/sqlserver/evidence/m1-port-proofs.txt`.

**Ranking by bill impact:** 1 (collation) and 4 (money scale) silently change amounts; 3 (dates) moves usage between billing days; the rest are errors or performance.

**Where each fix lives.** Collation: EF model (`UseCollation`) + migration, and a real-DB test (J3). Money: EF model (`HasPrecision` on **every** decimal; consider a model-building convention `configurationBuilder.Properties<decimal>().HavePrecision(19, 4)` so nothing falls back to 18,2) + domain rounding before persistence. Dates: domain (UTC normalization already there) + a check constraint `DATEPART(TZOFFSET, occurred_at) = 0` if you want the database to enforce it. Upsert: adapter.

**Tests.** Unit tests on `main` catch none of 1–4 (no database). Only tests against a real SQL Server (J3 pattern) catch them.
