# Separate lab review

## Review answers and rubric

For MF-09A, the quantity-conflict check is the sole intentional starter failure; build failure is never counted as successful mutation detection. For MF-09B, require the stable conflict code as well as unchanged stored data. For MF-09C, use hosted API tests for response and policy behavior, a shared-store concurrency fixture for contention, and a durable adapter with process-lifetime testing for restart claims. Full credit requires explicit scope and preserved source, not simply a green final console line.
